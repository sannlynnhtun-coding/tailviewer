# Tailviewer 2.0.0-alpha.2 — Avalonia preview

Branding update for this repository's .NET 10 / Avalonia desktop prototype, based on the original MIT-licensed Kittyfisto/Tailviewer project. This preview does not include all features of the legacy WPF application.

## Download and run

1. Download `tailviewer-2.0.0-alpha.2-win-x64.zip` and `SHA256SUMS.txt` from this release.
2. Optionally verify the ZIP with `Get-FileHash .\tailviewer-2.0.0-alpha.2-win-x64.zip -Algorithm SHA256` and compare it with `SHA256SUMS.txt`.
3. Extract the ZIP into a writable folder and run `Tailviewer.Avalonia.exe`.
4. Choose **Open file…**, or pass a log path: `.\Tailviewer.Avalonia.exe "C:\logs\application.log"`.

The Windows x64 portable package includes .NET 10.0.15 and Avalonia 12.1.6. No separate runtime installation or administrator access is required. The executable is not code-signed. No installer or Linux/macOS binary is provided.

## New in this preview

- New transparent log-lines-and-tail logo in the existing blue/white palette.
- Matching header, titlebar/taskbar and executable icons; legacy WPF/installer/NuGet icon paths receive the same design.
- Download `tailviewer-branding-2.0.0-alpha.2.zip` for the transparent master, 13 PNG sizes, nine-frame ICO, generation brief and license.
- Light/dark theme checks now use real Skia rendering, with 14 passing prototype integration tests.

## Included

- Local file opening, virtualized vertical/horizontal scrolling, and line-level selection/copy.
- Live tailing, unfinished-line updates, and follow/pause controls.
- UTF-8 defaults and byte-order-mark detection, including UTF-16.
- Core fixes for detected same-size replacement, rename rotation, truncate-and-regrow, and file disappearance/reappearance.
- Migrated API/Core with a .NET 10 target; the original WPF application remains in the source tree.

## Validation and limits

The prototype has 14 passing Core-backed Avalonia headless integration tests. The migrated Core suite has 6,641 passing tests and 5 existing skips on Windows. A 20,000-line test checks viewport virtualization; 100 MB/1 GB performance comparisons have not been completed.

Light/dark client-area rendering and the packaged logo are covered by real Skia headless tests. Native file picker interaction has not been fully verified; prior automated desktop capture timed out. Linux/macOS execution is unverified. This is an alpha release for evaluation.

Replacement detection uses metadata plus the first/last 4 KiB of previously read content. Rewrites outside those samples can be missed if metadata does not distinguish them. Rotated files retain the encoding detected at open time; reopen the file if its encoding changes. Selection copies whole lines, and large copies require memory for that text.

Search, filtering, merged sources, bookmarks, parsed columns, plugins, and installer/update flows are not part of this preview. The package uses the modern .NET 10 dependency graph; legacy source targets still have a log4net 2.0.12 advisory.

## Reproduce the package

From the repository root with the SDK selected by `global.json`:

```powershell
dotnet test Tailviewer.Avalonia.slnx --configuration Release
dotnet test src/Tailviewer.Core.Tests/Tailviewer.Core.Tests.csproj --framework net10.0 --configuration Release
dotnet publish src/Tailviewer.Avalonia/Tailviewer.Avalonia.csproj --configuration Release --runtime win-x64 --self-contained true -p:RuntimeFrameworkVersion=10.0.15 -p:PublishTrimmed=false -p:PublishSingleFile=false -p:DebugType=None -p:DebugSymbols=false --output artifacts/publish/tailviewer-2.0.0-alpha.2-win-x64
```

The published folder is distributed with the original `LICENSE`, `README.md`, and these release notes. `SHA256SUMS.txt` records the final ZIP's SHA-256 digest.
